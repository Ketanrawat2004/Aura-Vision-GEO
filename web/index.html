AuraVision GEO Architecture & Specification

Built strictly in accordance with the agentskills.io standard for the Adobe University Hackathon 2026.

1. Single-Pass Execution

Normalizes root domain and executes exactly 1 HTTP GET per route. Shares the parsed response across all 4 worker skills to complete comprehensive multi-pillar audits in < 5 seconds.

2. Mathematical Severity Matrix

Never guesses severity. Re-derives it mechanically from an immutable 3×3 (Impact × Scope) matrix: Blocking sitewide yields Critical, Degrading sitewide yields High, and Cosmetic yields Low.

3. Jaccard Deduplication

Merges overlapping worker findings using Jaccard token similarity (threshold ≥ 0.60), preserving the most specific technical title while unioning underlying evidence.

4. Zero External Dependencies

100% pure Python 3.8+ standard library (urllib, html.parser, xml.etree, json, gzip). Package size is < 0.5 MB, well under the 50 MB budget.
